# Mypos

A lightweight, chat-triggered utility mod for Minecraft. Get your exact coordinates without the clutter of the F3 debug screen.

## 🚀 Overview
Mypos provides simple, non-intrusive chat commands to retrieve your current location. Designed for technical players and builders who need precision without breaking their gameplay flow.

## 📖 Documentation
For a full list of commands, version logs, and roadmap, visit our official documentation:
👉 **[View Full Documentation](https://mintlify.wiki/allen-wang-2001/mypos)**

## 🎮 Usage
| Command | Action |
| :--- | :--- |
| `mypos` | Returns your coordinates privately. |
| `i am at mypos` | Broadcasts "I am at (coords)" globally. |
| `mypos-exact` | Returns exact coords |
| `i am at mypos` | Broadcasts "I am at (exact coords)" |
